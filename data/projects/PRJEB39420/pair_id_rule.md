# PRJEB39420 Pair ID 生成规则

## 配对类型
**年龄时间配对**

## 命名模板
`{subject_id}_{age_years}_y`

## 数据来源
**SraRunTable.csv → host_subject_id + 年龄(年)**

## 示例
- `11712-1_0.0301_y` → 婴儿11712-1，出生后11天
- `11712-10_0.0055_y` → 婴儿11712-10，出生后2天

## 验证规则
- pair_id = subject + "_" + age(年) + "_y"
- 年龄单位为年 (0.0055y ≈ 2天)
