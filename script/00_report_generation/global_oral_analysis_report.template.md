## Report Scope

This report summarizes the curated global oral 16S rRNA sequencing dataset and the downstream analyses prepared for manuscript development. It is designed as a source document for SCI manuscript writing: each section records the analysis purpose, input data, statistical method, main figure(s), figure-style legend, and source code/output paths.

Authoritative decisions used in this report:

- The final metadata/QC rules are defined by `new_analysis/generate_metadata_tables.py`.
- The raw merged QC input table is generated by `new_analysis/merge_all_for_qc_raw.py`.
- Detailed QC visualization is available in `new_analysis/data_qc_pipeline.html`.
- Detailed GG2 closed-reference profiling is available in `ASV_vs_HOMD_analysis/containment_derep/closed_reference_report/GG2_closed_reference_profile_report.html`.
- When multiple similar outputs exist in the same analysis directory, the final named output generated by the latest analysis script is treated as the main version; intermediate plots are reserved for supplementary material.

## 1. Data Processing Workflow

### 1.1 Metadata Collection and Curation

Metadata were collected project by project from public repository run tables, associated publications, and supplementary tables when available. The project-level curation workflow is documented in per-project notebooks such as `global-oral-microbiome/data/projects/PRJDB5440/metadata_curation_v2.md`.

For each study, the curation workflow included:

- Loading raw SRA metadata, typically from `SraRunTable.csv`.
- Reviewing the article abstract, results, and methods to identify study design, sample source, disease status, oral sampling site, and sequencing protocol.
- Removing control samples and non-human samples when present.
- Harmonizing the curated metadata into a common template containing sample ID, subject ID, age, sex, BMI, 16S region, platform, country, site, site group, publication time, primers, disease study indicator, disease/control status, matched-sample flag, and time-series flag.
- Manually resolving fields marked as `pending`, especially sampling site, site group, sex, disease status, and matched-sample structure.

The final cleaned metadata table used as the base for QC merging was `metadata_v2_merge/metadata-v2-merge-cleaned.csv`.

### 1.2 Merging QC Metrics

The script `new_analysis/merge_all_for_qc_raw.py` left-joined all QC-relevant inputs onto the authoritative cleaned metadata by `(bioproject, sample_id)`. The merge preserved the base metadata row structure and added sample-level sequencing and profiling metrics.

Inputs included:

- ASV counts: `new_analysis/sample_asv_counts_new.tsv`
- Chimera estimates: `new_analysis/oral_chim_perc_YL_260519.csv`
- Raw read counts: `new_analysis/raw_reads_stats.tsv`
- Alpha diversity metrics: `new_analysis/alpha_diversity_data.csv`
- GG2 closed-reference mapping fractions: `ASV_vs_HOMD_analysis/containment_derep/unified_gg2_closed_reference_profile/all_samples_gg2_closed_reference_mapping_fraction.tsv`

The merged QC input was written to `new_analysis/metadata_all_for_qc_raw.tsv`.

### 1.3 Final QC Filtering

The final QC tables were generated by `new_analysis/generate_metadata_tables.py`. The current authoritative rules are:

- Remove abnormal studies based on oral samples only if more than 50% of oral samples have `ASV <= 30`, more than 30% of oral samples have chimera percentage `>25%`, or the study-level closed-reference mapping rate is `<30%`.
- Remove remaining samples with `ASV <= 30`.
- Remove remaining samples with sample-level closed-reference mapping rate `<30%`.
- Remove remaining samples with missing observed alpha diversity or missing subject ID.
- Keep oral samples where `site_group == "oral"` for oral analyses.
- Generate the deduplicated oral table by retaining one sample per `(subject_id, site_cleaned)`.

The same script regenerated matched BIOM tables:

- `new_analysis/biom_all_qc.biom`
- `new_analysis/biom_oral_qc.biom`
- `new_analysis/biom_oral_qc_dedup.biom`

## 3. Alpha Diversity

### Method

Alpha diversity analysis used Shannon diversity from the non-deduplicated oral QC metadata. The script `new_analysis/alpha_diversity/run_shannon_mixed_model.R` fitted a linear mixed-effects model:

```text
Shannon ~ Sex + Age_Group + Site_Cleaned + Region_custom + Geography + (1 | BioProject)
```

Reference levels were Female, 18-60 years, Saliva, V4, and Asia. Fixed-effect significance was evaluated using model-based tests from `lmerTest`, and p values were adjusted with Benjamini-Hochberg FDR. Overview boxplots were also generated for major covariates.

### Key Results

The ANOVA table showed significant associations for sex, age group, site, 16S region, and geography. The strongest global effects were observed for age group and geography, while sequencing region remained a significant technical covariate and was retained in downstream models.

![Shannon forest plot](../new_analysis/alpha_diversity/shannon_forest_plot.png)

**Figure 8. Fixed effects associated with Shannon diversity in a BioProject-adjusted mixed model.**  
Points show model coefficients and horizontal bars show 95% confidence intervals relative to the reference group. The model included sex, age group, oral site, 16S region, geography, and a random intercept for BioProject. Color denotes FDR-adjusted significance.

## 6. Sequencing Region, Sex, and Age-associated Microbes

### Method

Differential abundance analyses were performed using MaAsLin3 on genus-level relative abundance tables. The standard preprocessing loaded genus relative abundance and cleaned metadata using `new_analysis/maaslin3/input_helpers.R`.

For site-stratified analyses, `new_analysis/maaslin3/run_site_stratified_analysis.R` fitted one MaAsLin3 model per oral site using the deduplicated oral QC metadata:

```text
genus abundance ~ Age_Group + Sex + Region_custom + Geography + (1 | BioProject)
```

Models used total-sum scaling normalization, log transformation, BH correction, `min_prevalence = 0.1`, and random intercepts for BioProject when supported by the data. Sites with at least 50 samples were analyzed.

For saliva-focused sex analyses, `new_analysis/maaslin3/run_saliva_sex_downsampled_na.R` performed stratified downsampling of North America saliva samples to reduce geographic imbalance, then fitted geography-specific MaAsLin3 models:

```text
genus abundance ~ Age_Group + Sex + Region_custom + (1 | BioProject)
```

North America downsampling was stratified by BioProject, sex, age group, and sequencing region.

## 7. Geographic Differential Abundance

### Method

Geographic differential abundance was analyzed in saliva using pairwise continent comparisons in `oral-v2-code-results-YL/02-continent-differential-analysis/01-analysisl-continent-maaslin3-array-pairwise-saliva.R`. Each Slurm array task compared one continent pair using MaAsLin3.

The model included continent as the main exposure and dynamically retained covariates with adequate factor support:

```text
genus abundance ~ continent_group + age group + sex + platform + sequencing region + BMI
```

When BioProjects were shared across the two compared continents, a BioProject random intercept was added:

```text
genus abundance ~ continent_group + covariates + (1 | BioProject)
```

MaAsLin3 settings included TSS normalization, log transformation, standardization, `min_prevalence = 0.05`, and `qval < 0.05` for significant pairwise associations.

## 8. Disease-associated Microbes

### Method

Disease differential abundance was analyzed using `new_analysis/maaslin3/run_disease_analysis.R` and visualized with scripts in `new_analysis/maaslin3/disease_shared_plots`. The analysis used deduplicated oral QC metadata and genus-level relative abundance.

For each disease, only BioProjects containing both disease cases and healthy controls were retained. Diseases were analyzed when there were at least 30 cases, 30 controls, and at least two matched BioProjects. The MaAsLin3 model included disease status as the primary exposure and retained available covariates:

```text
genus abundance ~ Disease_Status + Age_Group + Sex + Site_Cleaned + Region_custom + Geography + (1 | BioProject)
```

Covariates with fewer than two levels in a disease-specific subset were dropped. Models used TSS normalization, log transformation, BH correction, and `qval_individual < 0.1` for disease-associated genera.

Completed disease models currently include Dental Caries, Head and Neck Cancer, HIV, OSCC, Periodontal Disease, RA, Breast Cancer, CRC, IBD, and Lung Cancer.
