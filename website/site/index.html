The reference gap

GG2 closed-reference mapping rate — the fraction of a sample's reads that match a reference sequence — is lower in non-Western oral microbiomes, even after holding amplicon region constant.

Amplicon-adjusted continent effect

Study-level weighted logit regression of mapping rate on continent + amplicon region (reference = North America). Points are odds ratios of a read mapping; bars are 95% CIs. Red = significant reference deficit.

Odds ratio < 1 means reads from that continent map to the reference at lower odds than North America at the same amplicon. OR shown on a log axis.

Standardized data tables

Feature tables (BIOM) and harmonized metadata (TSV), matched by sample ID. Large binary artifacts are archived at a permanent DOI; this portal hosts the interactive views and small aggregates.

How this atlas is built

Fully reproducible: one script turns the metadata TSVs and the genus BIOM into the static JSON this page reads. No server or database at serve time.

website/precompute/build_data.py
Reads metadata + genus BIOM → overview / studies / taxa / refgap JSON
website/site/
Static front-end (this page). Deploy as-is to Cloudflare Pages / any static host.
